# EcoGrid – Power Plant Emission Risk Classifier

## Overview
EcoGrid is a machine learning-based application designed to classify power plant emission risk levels using environmental and operational data.

## Objectives
- Analyze power plant emission-related data.
- Process relevant features for machine learning.
- Predict emission risk categories.
- Support data-driven environmental risk assessment.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Machine Learning
- Streamlit (if used in the application)

## Project Structure
- `app.py` – Main application.
- `run_pipeline.py` – Data processing and model pipeline.
- `models/` – Model-related files.
- `utils/` – Helper functions.
- `requirements.txt` – Project dependencies.

## Installation

```bash
git clone https://github.com/KrishnaPriya030/ecogrid.git
cd ecogrid
pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run app.py
```
